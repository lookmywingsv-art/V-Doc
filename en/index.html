Key Takeaways

Four key judgments

Four sentences for leadership, each tied to a concrete action.

01

Agents will be the next "commerce + ads" super gateway

Discovery, purchase and ad buying will soon fit into a single conversation. ChatGPT already sells ads while accepting payments, and one Shopify integration reaches every major Agent. TikTok has content, products and ad delivery all in one place, which is the strongest card we hold: connect products, creatives, campaigns and conversion data into Agents together, and be first to make "conversation equals conversion" work.

02

Whoever the Agent thinks of first wins

Everyone has an MCP now. The deciding factor is whether an Agent finds TikTok first and uses it well. This is SEO for the Agent era: write clear tool descriptions, structure the data, fight hard for launch placement and default recommendations, and run "call hit rate" as the North Star metric.

03

Tier Agent partnerships, and land customers in Ads Manager

Complete standard integrations with ChatGPT and Gemini first so TikTok can be called; push deep integrations with Claude, Canva, Shopify and Doubao for default recommendations and co-marketing. The Agent proposes plans and drafts; final confirmation, payment and fine-tuning happen back in Ads Manager, so advertiser accounts and data stay on TikTok.

04

Ship "one-sentence Skills" for four high-frequency tasks in Q4

Few ad platforms today let advertisers launch campaigns directly inside 3P Agents. In Q4, prioritize turning Smart+ campaign creation, creative diagnosis, budget adjustment and weekly report generation into Skills an advertiser can run with one sentence, with spend caps and a second confirmation, measured by write-operation share and task success rate.

01 / 12Work is moving to general-purpose Agents

Reading reports, diagnosing, producing creatives and building campaigns increasingly start with a one-sentence prompt instead of opening Ads Manager. Most SMBs already use AI: a Constant Contact survey of 1,500+ SMBs across 5 countries in Q1 2026 found 54% already use AI marketing tools and another 27% plan to within the year; the top uses are trend analysis (45%), writing content (44%) and making images (40%).

The other gateway is Agents built into work software. Gartner forecasts that 40% of SaaS applications will embed task-specific Agents (built-in AI assistants that handle specific tasks) in 2026, up from under 5% in 2025. Advertisers will likely call TikTok directly through the built-in Agent of software they use every day.

Scenario 1 · E-commerce seller
Launch a new product on TikTok with one sentence from the Shopify admin

A merchant asks Shopify's built-in assistant Sidekick: "How should I promote this new product?" Sidekick pulls inventory, margin and recent sales, then recommends TikTok ads; once the merchant confirms, it calls TikTok directly to build a Smart+ campaign linked to the product catalog, all without leaving the store admin.

Scenario 2 · Marketer or designer
Finish a video in Canva, then turn it into a TikTok ad

After making a 15-second vertical video with Canva AI, a designer says: "Run this on TikTok, $50 a day, for one week to start." The built-in Agent pushes the creative to TikTok, generates an ad draft, and guides the user back to Ads Manager to confirm and go live.

These scenarios are extrapolated from current product capabilities; actual features depend on what each platform ships. What both share: advertisers never need to open TikTok specifically, and can launch ads from the software they already use every day. TikTok therefore needs to integrate with these built-in Agents early.

Interaction won't stay plain-text chat either. The ChatGPT Apps SDK and MCP Apps already support interactive cards, tables and charts inside a conversation. Strong examples: Zillow shows a draggable listings map in ChatGPT; Instacart generates an editable cart and supports in-chat payment (launched December 2025, the first App to support Instant Checkout); Hex and Amplitude show interactive charts in Claude with switchable dimensions and time ranges, the closest form to ad reporting. On the other side, Google Ask Advisor and Amazon Ads Agent bring conversational capabilities into the ad console. The two forms will converge (author's view).

02 / 12MCP is now table stakes for ad platforms

The MCP SDK hit 97M monthly downloads (2026-05), with native support in Claude, ChatGPT, Gemini, Copilot Studio and Cursor. In December 2025, MCP moved to the Agentic AI Foundation under the Linux Foundation, and neutral governance put platform concerns to rest.

  • MCP is no longer a differentiator. Advertisers can compare Meta and TikTok ROAS in one prompt, so switching costs between platforms drop sharply.
  • Write access and safeguards now set platforms apart. Meta creates every new campaign paused; Amazon rolls multi-step operations into a single command; Snap lets advertisers grant permissions per Agent.
  • Other platforms are opening write access. Meta went GA on July 16 and added Partnership Ads in September; Microsoft and Snap have published write-access roadmaps, with broad availability expected within 6–12 months.
What it means for TT4B: Write operations should cover the full campaign lifecycle and chain into complete tasks. Earn trust with paused-by-default, spend caps, second confirmation and per-Agent permissions. Then layer partner Skills and vertical solutions on top to offer workflows no one else offers yet. The core metric: write operations as a share of all calls.

It looks like an app store, but differs in four key ways

  1. The Agent picks the tool. Most calls come from the model matching tool descriptions to the task. What wins: clear descriptions, high task success rates and fast responses.
  2. Installed doesn't mean used. One Agent can connect to several ad platforms and chooses again for each task. Retention comes from getting the job done every time.
  3. Platforms also run their own ads. ChatGPT and Gemini sell ads themselves, so partnerships need to highlight differentiated value, backed by a multi-platform footprint.
  4. Distribution is getting more granular. More calls now happen inside a Skill or workflow.

Three variables drive MAA per Agent: entry-point exposure (featured slots, default prompts, branded hubs, templates), authorization friction (Meta has cut it to 5–7 minutes with no app review, the industry benchmark) and first-task results.

05 / 12Ad buying meets commerce

Agents don't just help advertisers buy ads. They now sell ads too and drive transactions directly. Buying, selling and checkout are converging in a single conversation.

Winner
Booking

Spent over $1B on Google ads in a single quarter in 2018; 2024 marketing spend was $7.3B, 31% of revenue. Embraced a platform-controlled entry point, bought traffic aggressively, and converted it into members, app users and direct visits.

Left behind
Yelp, TripAdvisor

After their content was indexed, Google gave its own local and travel services top placement on results pages. Traffic stayed on Google, and their main recourse became years of antitrust litigation.

Additional reference
Zynga · Alexa Skills

Zynga made up 12% of Facebook's revenue in 2011. When the rules changed, FarmVille MAU fell from 80M to 20M. Alexa skills retained about 3% of users by week two, and 69% of skills had 0–1 reviews.

Six things the winners had in common

  1. Treat call priority as a metric to manage. Search-era winners invested in SEO; Canva and Context7 have clear tool descriptions and focused features.
  2. Invest heavily in default placement. Booking bought ads at scale; Canva and HubSpot aim to launch first every time; Shopify is on by default.
  3. Turn traffic into owned users. Booking converts to members and app users; Canva sends users back to its editor; Shopify routes checkout back to the store.
  4. Don't bet on a single platform. Shopify, Canva and HubSpot integrate with ChatGPT, Claude, Gemini, Copilot and other Agents at once; Zynga bet only on Facebook.
  5. Build trust with public data. Atlassian and Supabase publish call volume and results.
  6. Solve visibility first, then scale. Alexa had plenty of skills, but users couldn't find them; the winners secured recommendation slots and high-frequency use cases first.
Why not other analogies
  • WeChat Mini Programs: grew through social sharing, and Agents have no equivalent viral loop.
  • App Store: depends on users searching and installing, while most Agent calls are chosen automatically by the model.
  • Payment networks, header bidding (programmatic ad auctions): closer to protocol battles, and explain only part of the picture.
10 / 12Strategy and four core levers

Four core levers across every direction

These aren't new tasks. They're the shared method behind all five directions. When resources are tight, protect these four first and watch two metrics: task success rate by Agent and share of write operations.

1 · Get Agents to call TikTok first

Write tool names and descriptions in advertisers' own words ("check my TikTok ad results," "create a Smart+ campaign"); keep tools few and focused; build a test question set and measure hit rate by Agent on a regular cadence.

2 · Win default entry points

Pursue launch partnerships, starter prompts, templates and industry showcases. Aim to be in the first wave at every new entry point (Claude Marketplace, the ChatGPT plugin directory, WorkBuddy Buddy apps).

3 · One-click authorization, success on first use

Meta already offers OAuth sign-in with no developer credentials; Amazon still limits access to API partners. That's our opening to pull ahead. Package high-frequency tasks as Skills so the first use delivers results.

4 · Earn trust for write operations with safeguards

New items paused by default, spend caps, second confirmation, per-Agent authorization; write operations should chain into complete tasks rather than scattered single-purpose endpoints.

Five priority directions

  1. Coverage: general and workflow Agents in parallel. General Agents (ChatGPT, Gemini, Claude, Copilot, Doubao) set the ceiling on reach, so secure integration first. Workflow Agents (Canva, Shopify, Mailchimp, Wix, GoDaddy Airo) carry clearer intent, so prioritize deep integration. Example combo: create assets in Canva → build a Smart+ ad in one step with TikTok MCP → review reports and adjust budget in ChatGPT or Claude.
  2. Usage: from listed to called by default. Discoverable → low-friction authorization → successful first use (e.g., checking yesterday's spend) → habit (weekly reports).
  3. Outcomes: package high-frequency tasks as one-sentence Skills. Start with four: creating Smart+ ads, creative diagnostics, budget adjustments and weekly reports.
  4. Investment: allocate by marginal MAA. Rank by "expected new MAA ÷ resources invested" instead of spreading effort evenly (see chart below).
  5. Trust: permissions and spend safety. Authorization per Agent, revocable at any time; spend caps and second confirmation for budget-related write operations; a full, auditable activity log.

Five takeaways for TT4B

  1. Manage Agent calls the way we manage SEO. Test hit rate regularly with a question set and refine tool descriptions accordingly.
  2. Pursue launch slots and default recommendations, with zero setup. Aim for the first wave at every new entry point, with no configuration needed after the first authorization.
  3. Stay balanced across platforms. Go deep with relatively neutral Agents (Claude, Kimi, Manus, Perplexity) and Doubao, and keep backing open protocols (MCP, Skills).
  4. Bring users back to TikTok Ads Manager. Agents generate plans and drafts; confirmation, payment and fine-tuning happen in Ads Manager, turning Agent traffic into our own advertisers.
  5. Publish usage data. Follow Atlassian's lead and regularly share MCP monthly actives, call volume and success stories.
